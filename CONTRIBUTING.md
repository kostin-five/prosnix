# Вклад в Prosnix

Это pet-проект для портфолио. Перед изменениями прочитайте `AGENTS.md`, конституцию и текущий handoff.
Обсудите изменение API, сценария, интеграции или схемы через OpenSpec. Небольшой bugfix должен иметь
проверку реального сбоя, а не тест, повторяющий реализацию.

## Локальная работа

- Начните с `pnpm install --frozen-lockfile` и `pnpm dev:demo`; ключи не нужны.
- Используйте Node 22–24 и pnpm 11.19.0, TypeScript strict и Prettier.
- Разделяйте код по ответственности; файлы исходников не должны превышать 1000 строк.
- Проверяйте `pnpm verify:release`, изменения API и БД — дополнительно на отдельной тестовой БД.
- Миграции только новые: уже применённые файлы не редактируются.
- В PR объясните изменение, причину, проверки и ограничения. Не добавляйте чужие правки.

## Данные и секреты

Не прикладывайте `.env`, токены, cookie, Telegram initData, дампы БД и реальные ответы. Скриншоты
снимайте в изолированном demo. Не используйте production для интеграционных тестов.
Об уязвимостях сообщайте приватно: см. `SECURITY.md`.

Код и собственные материалы проекта распространяются под MIT (`LICENSE`). Вклад должен быть
совместим с этой лицензией; условия сторонних ресурсов сохраняются.
