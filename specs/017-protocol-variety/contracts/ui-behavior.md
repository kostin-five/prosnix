# UI-контракт

## Стакан воды

1. При открытии шага запускается видимый таймер от 10 до 0 секунд.
2. Кнопка «Выпил» заблокирована, пока значение больше нуля.
3. После нуля кнопка становится доступна и использует существующую single-flight отправку.
4. Повторное нажатие не создаёт результат следующего шага.

## Персональный отчёт

Готовый отчёт показывает заголовок, summary, caveat и при необходимости время следующего
обновления. Отдельная техническая подпись `{evidenceCount} подтверждённых сессий · {source}` не
отображается. Серверный контракт не меняется.
