# Проверка: разнообразная калибровка протоколов

**Дата**: 15 сентября 2026 года

## Подтверждено автоматически

- `pnpm format:check` — пройдено;
- `pnpm typecheck` — пройдено;
- `pnpm test` — пройдено: domain 41, web 35 и API 68 тестов; 15 PostgreSQL integration tests
  пропущены без отдельной тестовой БД;
- `pnpm build` — пройдено;
- `pnpm verify:web-bundle` — пройдено: 238,0 КиБ из лимита 240 КиБ;
- целевой regression подтверждает семь разных составов, максимум четыре появления математики,
  памяти и реакции, три появления приседаний и мягкое движение перед каждым из них;
- component regression подтверждает блокировку воды на 10 секунд;
- regression текста подтверждает отсутствие отдельной технической подписи персонального отчёта.

## Не выполнялось

- `pnpm test:integration`, `pnpm verify:release:full` и production deploy не запускались: они
  требуют отдельной тестовой PostgreSQL и явного решения владельца о выпуске;
- ручная Telegram-проверка protocol version 7 остаётся в
  `docs/pre-pilot-manual-test-plan.md`.

## Результат

Локальная реализация соответствует спецификации. Для выпуска нужны CI, deploy одного точного SHA и
короткая ручная повторная проверка изменённого каталога, воды и подписи отчёта.
