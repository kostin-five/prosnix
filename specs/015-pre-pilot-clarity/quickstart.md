# Quickstart

1. Проверить ResultsScreen при server evidence count 14 и во время analytics loading.
2. Проверить профиль без повторной цифровой KPI-сетки, с рекомендацией и дедуплицированным progress.
3. Проверить график на положительном, нулевом и отрицательном session delta.
4. Проверить Coach fallback с лучшей последовательностью и prompt без пересказа среднего.
5. Проверить малые SVG и mobile E2E на 320–390 px.
6. Выполнить `pnpm verify:release`; API/DB schema не меняются.
