# Модель данных

Новые сущности и поля не добавляются.

## Используемые данные

- `WakeSession.durationMinutes` определяет нагрузку 2/5/10 минут.
- `ExperimentAssignment.protocolVersion` и `strategyVersion` отделяют новые правила от старых.
- `TaskObservation.correct` хранит число успешных раундов.
- `TaskObservation.total` хранит все принятые попытки, включая неправильные.
- `TaskObservation.durationMs` хранит фактическую длительность задания.

## Правила

- Для новых когнитивных протоколов `correct` не меньше целевого значения для task и бюджета.
- `total >= correct` сохраняется.
- Ошибки не удаляются и не превращаются в успешные ответы.
- Исторические observations не переписываются.
- Новые назначения используют `window` как единственный световой task ID; существующий
  `curtains` остаётся допустимым только для чтения и завершения старых сессий.
