# Контракт завершения задания

Форма `PUT /api/v1/sessions/:sessionId/steps/:stepIndex` не меняется.

Начиная с protocol version 3:

| Задание                           | 2/5 минут       | 10 минут        |
| --------------------------------- | --------------- | --------------- |
| Математика                        | 3 успеха        | 5 успехов       |
| Внимание                          | 3 успеха        | 5 успехов       |
| Реакция                           | 3 сигнала       | 5 сигналов      |
| Память                            | 2 раунда        | 3 раунда        |
| Движение, поведение или окружение | 1 подтверждение | 1 подтверждение |

Если `correct` ниже цели или `total < correct`, сервер отклоняет переход и возвращает canonical
session через существующий conflict contract. Повтор с новым idempotency key и достаточным
результатом принимается при актуальном `If-Match`.

Protocol versions 1/2 сохраняют прежнюю общую валидацию ради активных сессий. Version 3 сохраняет
строгие цели, а новые назначения version 4 дополнительно фиксируют семь шагов и порядок разминки.
Version 5 назначает единый световой шаг `window`; сохранённый `curtains` остаётся завершаемым по тому
же существующему контракту подтверждения.
