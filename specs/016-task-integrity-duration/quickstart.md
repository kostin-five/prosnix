# Проверка feature

## Автоматически

```bash
pnpm format:check
pnpm typecheck
pnpm test
pnpm test:e2e
pnpm verify:release
```

Изменений schema нет; integration regression запускается в составе полного release gate на
отдельной PostgreSQL, если затронут repository path.

## Ручной smoke

1. В реакции нажать несколько раз до зелёного сигнала — счётчик остаётся на первом раунде.
2. На каждом зелёном сигнале сделать двойное касание — засчитывается один результат.
3. Во внимании дважды ошибиться, затем дать три правильных ответа — задание заканчивается только на
   третьем правильном.
4. В памяти ошибиться в первом вводе — показывается новая последовательность, прогресс остаётся
   нулевым; затем правильно воспроизвести требуемые последовательности.
5. В режиме 10 минут проверить цели 5/5/5/3 для назначенных когнитивных заданий и более длинные
   таймеры движения/света.
6. Создать сессии одинакового бюджета в двух контекстах: первый протокол может совпасть, но история
   сохраняет разные контексты, а evidence одного не выдаётся как результат другого.
7. В новых сессиях убедиться, что отдельные «Шторы» не назначаются, а «Яркий свет» предлагает
   дневной и комнатный вариант. Старую сохранённую сессию со шторами завершить без ошибки.
