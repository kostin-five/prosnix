# Проверка: Продуктовая админ-панель

**Дата:** 5 сентября 2026 года

**Среда:** ветка `dev`, отдельная локальная PostgreSQL

## Автоматические результаты

- `pnpm verify:release:full` — успешно;
- format и TypeScript strict — успешно;
- unit, contract и component: domain 19, web 14, API 65 — успешно;
- PostgreSQL integration: 13 из 13 — успешно;
- production build и boundary scan — успешно;
- dependency audit: известных production-уязвимостей нет;
- mobile Chromium E2E: 12 из 12, включая owner-only admin и отказ обычному пользователю;
- initial web bundle: 248,2 КиБ из лимита 250 КиБ;
- lazy admin chunk: 14,64 КБ, gzip 4,81 КБ.

## Проверенные свойства

- когорты используют левую включительную и правую исключительную границы периода;
- парный эффект исключает сессии без baseline или post-rating;
- нулевые знаменатели не создают `NaN` или `Infinity`;
- timeline содержит нулевые UTC-интервалы;
- feature-метрики ограничены выбранным периодом и не зависят от параллельных fixtures;
- ответ не содержит Telegram ID, UUID пользователей/сессий, индивидуальные оценки или тексты рутины;
- неавторизованный и не включённый в allowlist пользователь получает `404`;
- переключение 7/30/90 дней, loading, empty, error и retry покрыты component-тестами;
- страница остаётся без горизонтальной прокрутки на ширине 320 пикселей.

## Найденное и исправленное во время проверки

Первый единый параллельный integration-прогон выявил, что завершённые анкеты и включённые рутины
считались за всё время. Запрос исправлен: анкеты ограничены `onboarding_completed_at`, новые
включённые рутины — `created_at`, запуски рутины и AI-объяснения — своими временными полями внутри
`[from, to)`. Повторный полный release-прогон прошёл.

## Неавтоматизированные ограничения

- критерий производительности на 10 000 пользователей не подтверждён нагрузочным тестом;
- реальный Telegram smoke-test владельцем выполняется только после deploy;
- Android Telegram WebView требует отдельного физического устройства или device farm;
- этап не меняет БД и не требует новой миграции.
