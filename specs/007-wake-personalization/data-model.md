# Модель данных: Персонализация пробуждения

## Перечисления

- `wake_context`: `unspecified`, `night_sleep`, `short_nap`, `long_nap`, `energy_reset`.
- `movement_level`: `none`, `light`, `full`.
- Временной бюджет: 2, 5 или 10 минут.

## `wake_capability_profiles`

Одна текущая запись на пользователя.

| Поле                       | Смысл                                          |
| -------------------------- | ---------------------------------------------- |
| `user_id`                  | PK/FK пользователя, cascade delete             |
| `movement_level`           | Разрешённая интенсивность движения             |
| `available_resources`      | Массив: `water`, `bright_light`, `floor_space` |
| `excluded_task_ids`        | Проверенный массив идентификаторов заданий     |
| `default_duration_minutes` | 2, 5 или 10                                    |
| `onboarding_completed_at`  | null для пропущенной анкеты                    |
| `revision`                 | Положительная версия                           |
| `created_at`, `updated_at` | Служебные даты                                 |

Отсутствие записи означает консервативный профиль. Неизвестные значения отклоняются на API.

## Расширение `wake_sessions`

| Поле                       | Смысл                                                |
| -------------------------- | ---------------------------------------------------- |
| `wake_context`             | Неизменяемый контекст; старые строки — `unspecified` |
| `duration_budget_minutes`  | Неизменяемый бюджет; старые строки — 5               |
| `personalization_snapshot` | Версия профиля, ограничения и причина fallback       |

Поля устанавливаются при создании и не переписываются при изменении профиля.

## `wake_routines`

Одна текущая рутина на пользователя: `user_id`, `enabled`, упорядоченный JSON-массив 0–5 объектов `{id, title}`, `revision`, даты. Название очищается по краям и имеет длину 1–80 символов.

## `wake_routine_runs`

Не более одной записи на сессию: `session_id`, `user_id`, снимок пунктов, множество отмеченных id, `revision`, даты и `completed_at`. Запуск разрешён только владельцу завершённой сессии; отмечаются только id из снимка.

## Связи и аналитика

- Удаление пользователя каскадно удаляет профиль, рутину и выполнения.
- Удаление сессии удаляет её выполнение рутины.
- Аналитические projections и observations не зависят от таблиц рутины.
- История возвращает контекст и бюджет, выполнение рутины — отдельной необязательной информацией.

## Миграция

`0005_wake_personalization.sql` создаёт перечисления/таблицы и добавляет поля с безопасными default. Она forward-only, не изменяет `0000`–`0004` и не удаляет существующие данные.
