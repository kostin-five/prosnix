# Быстрая проверка: Персонализация пробуждения

## Локальная среда

```bash
corepack enable
pnpm install --frozen-lockfile
cp .env.example .env
pnpm db:start
pnpm db:migrate
pnpm dev
```

Открыть `http://localhost:5190/?demo=1`. Production Neon для проверки не используется.

## Профиль и фильтрация

1. В настройках выбрать лёгкое движение, отключить воду и исключить приседания.
2. Сохранить и перезагрузить приложение.
3. Начать пробуждение, выбрать короткий дневной сон и 2 минуты.
4. Проверить отсутствие воды и приседаний и отображение контекста в истории.

## Безопасный fallback

1. Запретить движение, убрать ресурсы и исключить несколько когнитивных заданий.
2. Начать сессию.
3. Проверить, что старт доступен, ограничения соблюдены и причина fallback понятна.

## Рутина

1. Создать три пункта в настройках.
2. Завершить измеряемую часть сессии и отметить два пункта.
3. Перезагрузить приложение и проверить восстановление прогресса.
4. Убедиться, что аналитика до и после отметок не изменилась.

## Автоматические проверки

```bash
pnpm format:check
pnpm typecheck
pnpm test
pnpm test:integration
pnpm build
pnpm verify:web-bundle
pnpm verify:production
pnpm test:e2e
```

Миграцию в production и deploy выполняет владелец только после успешного CI и отдельной проверки.
