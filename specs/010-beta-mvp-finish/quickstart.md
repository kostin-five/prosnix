# Проверка этапа 010

## Автоматические проверки

```bash
pnpm format:check
pnpm typecheck
pnpm test
pnpm test:integration
pnpm build
pnpm verify:web-bundle
pnpm test:e2e
```

## Ручной сценарий на 320 px

1. Открыть `http://localhost:5190/?demo=1` в mobile viewport 320 x 740.
2. Убедиться, что wordmark, Beta, подпись и счётчик не пересекаются.
3. Проверить, что на главной видны столбцы дневного прироста, значения и `n`.
4. Перейти в статистику и настройки: Beta остаётся видимой в заголовке.

## Ранний AI-отчёт

1. Использовать тестового пользователя с двумя завершёнными сессиями.
2. Нажать «Создать персональный отчёт»: увидеть предупреждение, provider не вызывается.
3. Нажать «Создать всё равно»: получить отчёт низкой уверенности.
4. Повторить запрос в тот же локальный день: увидеть cache без нового provider-вызова.

## Fallback

1. Запустить API без `DEEPSEEK_API_KEY` либо использовать failing test gateway.
2. Запросить отчёт при 3+ сессиях.
3. Проверить полезные закономерности, следующий эксперимент и ограничение; в UI нет слов `заглушка` или `DeepSeek недоступен`.
