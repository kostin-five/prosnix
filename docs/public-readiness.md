# Проверки перед публикацией

## Подготовлено

Настроены безопасные серверные журналы, проверка рабочей конфигурации, отдельная тестовая БД,
проверки секретов и зависимостей в CI. Крупные модули разделены. Доступны автономное демо,
локальный шрифт Inter, доступные диалоги, инструкция запуска и лицензия MIT.

Полная проверка до очистки включала 245 модульных и контрактных тестов,
27 интеграционных тестов PostgreSQL, 32 мобильных сквозных теста и тест собранного демо.
Проверка зависимостей 6 октября не выявила известных уязвимостей.
После очистки повторно прошли `verify:release` и `test:demo`; код и миграции не менялись.

## Очистка истории

По разрешению владельца удалены личные сведения, презентации и лишние документы.
Проверены доступные локальные ссылки Git, текстовые объекты, метаданные коммитов и оставшиеся изображения.
Реальные файлы окружения не читались.

Проверка 7 октября охватила 1 991 текстовый объект и 13 используемых изображений.
Известные личные маркеры не обнаружены; имена авторов и коммиттеров обезличены.
Старые ссылки, записи журнала перемещений ссылок и недостижимые объекты удалены локально.
Gitleaks не выявил секретов. Содержимое 292 файлов кода, тестов и миграций, а также README
сохранено побайтово.

## Проверка GitHub

После обновления очищенной истории прошли проверки обеих веток:
[dev](https://github.com/kostin-five/prosnix/actions/runs/37628240420) и
[master](https://github.com/kostin-five/prosnix/actions/runs/37628871748).

Проверены журналы 60 прежних запусков: 212 текстовых файлов. Gitleaks и поиск известных личных
маркеров не дали находок. Эти запуски и три старых кэша удалены; актуальные проверки сохранены.
На момент проверки не было сохранённых результатов сборок, ответвлений репозитория, выпусков,
отдельных обсуждений ошибок и комментариев. Wiki и Pages были выключены.
Четыре запроса Dependabot созданы от очищенной истории и проверены отдельно.

17 октября из текущего дерева исключены служебные материалы. Для коммита `7494963`
прошли проверки [dev](https://github.com/kostin-five/prosnix/actions/runs/39032622932) и
[master](https://github.com/kostin-five/prosnix/actions/runs/39032853041).
Публичный доступ к репозиторию подтверждён через API GitHub.

## Что требует отдельной проверки

Прежние коммиты оставались доступны через API GitHub по известным SHA. Принудительная отправка
веток и удаление запусков Actions не удаляют серверные объекты. Владелец направил обращение в
[службу поддержки GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)
об удалении кэшированных просмотров и серверной сборке мусора. После ответа нужно повторить проверку.
Удаление обычных материалов, не содержащих чувствительных сведений, поддержка не гарантирует.

Для работающего мини-приложения отдельно проверяются вход через Telegram, отчёт DeepSeek,
уведомления и голос на устройстве. Автоматические проверки не подтверждают происхождение
изображений и не гарантируют отсутствия всех рисков.
