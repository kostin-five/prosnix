# Проверки перед публикацией

## Выполнено

Безопасные серверные журналы, production validation, отдельная test-БД, обновлённые зависимости,
CI secret/dependency checks, модульный App и session repository, автономное demo, локальный Inter,
доступные диалоги, README и MIT.

Последний полный gate до очистки: 245 unit/contract, 27 PostgreSQL integration, 32 mobile E2E
и тест собранного demo. Dependency audit: 0 известных уязвимостей на дату проверки 6 октября.
Повторный verify:release 7 октября до очистки также прошёл. Код и миграции очисткой не меняются.

## Очистка истории

Владелец разрешил удалить личные сведения, презентации и лишние документы из всей локальной истории.
Проверяются все доступные локальные refs, текстовые объекты, метаданные commits, оставшиеся медиа,
секреты и неизменность кода/миграций. Реальные env не читаются. Подробности результата — в CURRENT handoff.

## Осталось снаружи

Разрешённое обновление remote веток и tags после сверки их фактических SHA, затем зелёный CI
и отдельное решение о публичности. GitHub PR refs, кэши и forks не очищаются локальными командами.
При сохранении live Mini App отдельно проверить Telegram, AI, уведомления и голос на устройстве.
Автоматические проверки не гарантируют отсутствие всех рисков и не подтверждают происхождение assets.
