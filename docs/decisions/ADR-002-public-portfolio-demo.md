# ADR-002: Публичные исходники и автономное демо

- **Статус:** принято
- **Дата:** 2026-10-06

## Контекст

Prosnix переведён в учебный проект. На момент решения пользователей и оплат нет.
Для демонстрации нужна версия без ключей, аккаунтов и персональных данных.

## Решение

Сохранить модульный монолит и доменные правила. Отдельная сборка Vite в режиме `portfolio`
использует вымышленные данные, запрещает обращения к API, не загружает Telegram SDK
и локальные файлы окружения. Рабочая сборка сохраняет серверную авторизацию.
Обе сборки проверяются отдельно.

Крупные модули разделяются по ответственности. Предел исходного файла — 1000 строк;
сгенерированные миграции и файл фиксации зависимостей исключены из этого ограничения.
Автоматические журналы сохраняют только разрешённые технические поля.
Интеграционные тесты требуют явно указанную локальную тестовую БД.
CI проверяет секреты в истории и все зависимости, включая инструменты разработки.

## Последствия

Демо можно показать без внешних сервисов. Оно не проверяет реальные интеграции и не доказывает
эффективность упражнений. Удаление файла из текущего дерева не удаляет его прежние версии.
Код и собственные материалы распространяются под MIT; условия сторонних материалов сохраняются.

## Уточнение от 7 октября

Работа продолжается в текущем репозитории `prosnix`. По разрешению владельца локальная история
очищена от личных сведений, презентаций и лишних документов. Метаданные авторов обезличены,
SHA коммитов изменились. Код, миграции и README сохранены.

Удалённые ветки обновляются с проверкой ожидаемых SHA. Сливать прежнюю историю с очищенной нельзя.
Кэшированные объекты GitHub требуют отдельной проверки и обращения в поддержку.
