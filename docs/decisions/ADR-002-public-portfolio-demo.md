# ADR-002: Публичное портфолио и изолированное демо

- **Статус:** принято владельцем как направление работы
- **Дата:** 2026-10-06

## Контекст

Владелец перевёл Prosnix в pet-проект: пользователей и оплат нет. Требуется показать техническую
работу без обещаний доказанной пользы и без передачи персональных данных в демонстрации.

## Решение

Оставить модульный монолит и текущие доменные правила. Создавать отдельную web-сборку `portfolio`
с синтетическими данными, запретом API-транспорта, без Telegram SDK и загрузки локального env.
Production-сборка остаётся авторизованной. Проверять обе сборки отдельно.

Разделять большие файлы по ответственности с пределом 1000 строк для исходников. Сгенерированные
миграции и lockfile исключены. Автоматические логи сохраняют только разрешённые технические поля.
Интеграционные тесты требуют явную локальную тестовую БД. В CI проверяются история секретов и все
зависимости, включая dev-инструменты.

## Последствия

Demo можно показать без ключей и аккаунтов. Это не проверка внешних интеграций и не доказательство
эффекта упражнений. История, изображения, лицензия и настройки видимости требуют отдельной оценки.
Удаление файлов из текущего дерева не очищает историю. Владелец согласовал MIT для кода и собственных материалов, включая логотип.

7 октября владелец выбрал продолжение работы в текущем prosnix с сохранением Git-истории.
Отдельная подготовленная копия не используется для выпуска. Исторические личные документы и
бинарные материалы остаются отдельной проверкой перед сменой публичности.
