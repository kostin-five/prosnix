# Планы Prosnix

Prosnix поддерживается как экспериментальный учебный проект. Коммерческое развитие остановлено.
Приоритет — работающий сценарий, понятный код, тесты и документация.

## Выполнено

- Настроены безопасные журналы, проверка конфигурации и зависимостей.
- Крупные модули разделены; доступны автономное демо и инструкция запуска.
- По разрешению владельца очищены документы, изображения и история Git.
- Из публикуемого дерева исключены локальные рабочие материалы.
- Документация приведена к русской терминологии; отдельные инструкции для внешних участников удалены.

## Следующие шаги

После ответа службы поддержки GitHub повторно проверить доступность старых коммитов по их SHA.
Обращение отправлено владельцем. Публикация исходников не подтверждает обновление работающего приложения:
развёртывание рабочей версии требует отдельного разрешения.

Размещение автономного демо остаётся отдельным решением.

## Идеи на будущее

Собственные шаблоны заданий и обмен протоколами. Это идеи, а не реализованные возможности
или обязательства по дальнейшему развитию.
