# Планы Prosnix

Prosnix поддерживается как экспериментальный pet-проект. Коммерческое развитие остановлено;
приоритет — работающий сценарий, понятный код, тесты и документация.

## Текущий этап

- Безопасные журналы, проверка конфигурации и зависимости.
- Модульные исходники, автономное демо и актуальный README.
- Очистка документов, изображений и Git-истории по разрешению владельца от 7 октября.

## Следующие шаги

Очищенная история, сборка и demo проверены. Владелец разрешил обновление GitHub и отключил
автодеплой обоих сервисов. Очищенные dev и master опубликованы; CI обеих веток для 6968da5
успешен. Внешняя проверка GitHub завершена: старые CI-запуски и кэши удалены. Старые commits
пока доступны по SHA; следующий шаг — обращение владельца в GitHub Support и повторная проверка
перед сменой публичности. Публичность и размещение автономного демо — отдельные решения.
Production deploy выполняется только по отдельному разрешению владельца.

## Идеи на будущее

Собственные шаблоны заданий и обмен протоколами. Это идеи, а не реализованные возможности
или обязательства по дальнейшему развитию.
