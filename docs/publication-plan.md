# Публикация Prosnix

Работа продолжается в текущем репозитории `prosnix`. По разрешению владельца из текущих файлов
и локальной истории Git удалены личные сведения, посторонние материалы и лишние документы.
Отдельная копия репозитория для публикации не используется.

## Состав репозитория

Публикуются исходники приложения, миграции, тесты, документация, лицензии и используемые изображения.
Локальные рабочие материалы исключены из отслеживания. Обычное удаление файла новым коммитом
не удаляет его прежние версии из истории.

## История и удалённые ветки

При переписывании истории меняются SHA коммитов. Нельзя сливать прежнюю историю с очищенной:
это вернёт удалённые материалы. Перед отправкой проверяйте фактические ветки и SHA удалённого
репозитория; не перезаписывайте чужие изменения и защищённые ветки.

Обновление с `--force-with-lease` допускается только по отдельному разрешению и с проверенным
ожидаемым SHA. Не используйте `push --mirror`. После отправки дождитесь проверок GitHub Actions.
Проверьте также другие ветки, метки версий, запросы на слияние и ответвления репозитория.

Кэшированные просмотры и старые объекты GitHub не удаляются локальной очисткой.
По личным сведениям в прежней истории владелец направил обращение в службу поддержки GitHub.
После ответа нужно повторно проверить доступность старых SHA.

## Приложение и демо

Очистка репозитория не включает развёртывание приложения, изменение входящих обработчиков Telegram
или секретов. Перед обновлением веток нужно проверить настройки автоматического развёртывания.

Статическое демо собирается в `apps/web/dist-demo`, не использует серверные переменные окружения
и не подключается к БД. Решение о его размещении принимается отдельно.
