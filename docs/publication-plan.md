# Публикация Prosnix

Работа продолжается в текущем репозитории prosnix. Владелец разрешил 7 октября убрать личные
сведения, посторонние материалы и лишние документы из текущего дерева и всей локальной Git-истории.
Новые копии репозитория не создаются. README владельца сохраняется.

## Очистка

Удаляются презентации, старые отчёты и handoff, маркетинговые черновики и неиспользуемые изображения.
Остаются приложение, спецификации, миграции, тесты, рабочая документация, MIT, шрифт и используемые assets.
Из исторических текстов удаляются найденные личные имена, email и домашние пути; метаданные commits
обезличиваются. Изменяются SHA commits; обычный pull из прежней истории больше не подходит.

## Обновление GitHub

После локальных проверок требуется отдельно разрешённое согласованное обновление remote.
Нельзя обычным merge вернуть старые commits: это восстановит удалённые материалы.
Перед обновлением проверить фактические remote refs и их SHA; защищённые ветки и чужие изменения
не перезаписывать автоматически. Не использовать push --mirror.

Поскольку локальная master является предком dev, актуальную проверенную версию можно перенести
fast-forward merge. Затем обновить dev и master с явными ожидаемыми SHA через force-with-lease
и дождаться CI. Другие удалённые ветки и tags также проверяются на наличие старой истории.
Сохранённые PR refs, fork и кэши GitHub требуют отдельной проверки: локальная очистка их не удаляет.

Production deploy и webhook не входят в очистку. Автодеплой проверить до обновления веток.
Для статического демо используется apps/web/dist-demo, без server env или БД.
