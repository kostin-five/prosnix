## Принятый вариант — текущий репозиторий

7 октября владелец отменил использование отдельной копии: все коммиты и последующая работа
выполняются в текущем `prosnix`, история сохраняется. Код и собственные материалы — MIT;
Inter и сторонние зависимости сохраняют свои лицензии. Новая история не создаётся.

1. Сохранить подготовленные исправления кода и документы коммитами в текущем dev.
2. Перед публичностью проверить исторические документы и бинарные материалы. Удаление из
   текущего дерева не скрывает старые версии. Gitleaks не выполняет OCR и не проверяет права на assets.
3. По разрешению владельца выполнить push dev в существующий remote и дождаться зелёного CI
   точного SHA. Не считать push разрешением на auto-deploy production.
4. Отдельно решить вопрос публичности репозитория с сохранённой историей.
5. Для портфолио можно разместить только dist-demo, без env, ключей, БД и API rewrite.

Черновики docs/design, assets/previews и assets/gemini/amber-protocol-preview не добавлять
автоматически. Ранее созданные соседние каталоги не являются источником для выпуска;
их удаление не входит в текущий запрос. История не переписывается, force-push не выполняется.
